Two fresh disposable installations; 13 original probes and 42 baseline calls each. Additional persistence and restart checks bring each transcript to 114 MCP calls. Each run has 12 MCP commit receipts (seed plus 11 gaps), 13 kernel receipts (including universe creation), and 14 revisions (including empty genesis).
